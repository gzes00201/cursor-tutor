# Cursor Workshop 綜合練習指南

## 🎯 課程目標
通過實際操作，讓學員掌握 Cursor 的各種功能，包括 TAB、Chat、⌘K、Rule、MCP 以及各種 Agent 功能。

## 📚 課程結構

### 第一階段：基礎功能 (60分鐘)
1. **TAB 功能練習** (20分鐘)
   - 智能代碼補全
   - 上下文理解
   - 與 GitHub Copilot 的比較

2. **Chat 功能練習** (20分鐘)
   - Agent Mode 基礎使用
   - Ask Mode 探索功能
   - @ 符號的使用

3. **⌘K 功能練習** (20分鐘)
   - 自然語言編輯
   - 區塊編輯和全文件編輯
   - 快速提問模式

### 第二階段：進階功能 (60分鐘)
4. **Rule 功能練習** (20分鐘)
   - 專案規則設定
   - 個人風格偏好
   - 規則效果測試

5. **MCP 功能練習** (20分鐘)
   - MCP 配置和使用
   - 外部工具整合
   - 實際應用案例

6. **Agent 功能練習** (20分鐘)
   - Background Agent 使用
   - Cursor Agent 進階功能
   - Bugbot 錯誤修復

### 第三階段：綜合應用 (60分鐘)
7. **專案實作** (40分鐘)
   - 使用所有功能完成一個完整專案
   - 最佳實踐應用
   - 問題解決

8. **總結和討論** (20分鐘)
   - 功能比較和選擇
   - 最佳實踐分享
   - 問題解答

## 🚀 練習流程

### 準備工作
1. 確保 Cursor 已安裝並更新到最新版本
2. 開啟練習專案：`cursor-workshop-exercises`
3. 熟悉專案結構和文件組織

### 練習順序
1. **按順序完成練習**：從基礎到進階
2. **實際操作**：每個功能都要親自體驗
3. **觀察效果**：注意 AI 的行為和回應
4. **記錄心得**：記錄使用體驗和發現

### 評估標準
- **功能理解**：是否理解每個功能的作用
- **實際操作**：是否能夠熟練使用
- **問題解決**：是否能夠解決實際問題
- **最佳實踐**：是否遵循最佳實踐

## 🔍 常見問題

### Q: 為什麼 AI 沒有按照我的期望工作？
A: 可能是提示不夠具體，或者需要提供更多上下文。嘗試：
- 使用更詳細的提示
- 使用 @ 符號引用相關文件
- 提供具體的範例

### Q: 如何選擇最適合的模型？
A: 根據任務類型選擇：
- **精確任務**：使用 Claude 3.5 Sonnet
- **廣泛應用**：使用 Claude 3.7 Sonnet
- **複雜推理**：使用 o3
- **自動選擇**：使用 Auto 模式

### Q: Rules 沒有生效怎麼辦？
A: 檢查以下幾點：
- 規則是否保存在正確位置
- 規則是否具體且可操作
- 是否重啟了 Cursor
- 是否在正確的模式下使用

### Q: MCP 伺服器無法連接？
A: 檢查以下幾點：
- 配置文件是否正確
- 依賴是否已安裝
- 環境變數是否設置
- 網路連接是否正常
