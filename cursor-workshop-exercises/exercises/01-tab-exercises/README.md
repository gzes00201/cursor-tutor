## 🎯 學習目標

- 學會如何有效使用 Tab 來加速編程
- 掌握 Tab 的上下文理解能力
- 了解 Tab 與 GitHub Copilot 的差異

## 🚀 開始練習
1. 開啟對應的練習檔案
2. 按照檔案中的註解指示進行操作
3. 使用 Tab 鍵來接受建議
4. 觀察 Tab 如何理解上下文並提供相關建議

## 💡 提示
- Tab 會根據你的代碼上下文提供建議
- 可以通過註解來引導 Tab 的建議方向
- 如果建議不正確，可以繼續輸入來提供更多上下文
- 使用 `Ctrl+→` (Windows/Linux) 或 `Cmd+→` (Mac) 來接受部分建議
