## 🚀 開始練習
1. 使用 `⌘+L` (Mac) 或 `Ctrl+L` (Windows/Linux) 開啟 Chat
2. 按照練習題目中的指示進行操作
3. 嘗試不同的模式和 @ 符號組合
4. 觀察 AI 如何理解和回應你的請求

## 💡 提示
- Agent 模式適合複雜任務，會自動執行多個步驟
- Ask 模式適合探索和學習，不會修改代碼
- Manual 模式適合精確控制，需要明確指定文件
- 使用 @ 符號可以讓 AI 更好地理解上下文
- 不同的模型有不同的特性和適用場景
