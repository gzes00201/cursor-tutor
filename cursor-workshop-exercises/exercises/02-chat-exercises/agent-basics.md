# Agent Mode 基礎練習

## 🎯 練習目標
學習 Agent 模式的基本使用，體驗 AI 如何自動完成複雜任務

## 📋 練習步驟

### 練習 1: 創建簡單的待辦事項應用
**任務**: 使用 Agent 模式創建一個基本的待辦事項應用

**操作步驟**:
1. 開啟 Chat (`⌘+L` 或 `Ctrl+L`)
2. 確保選擇 Agent 模式
3. 輸入以下提示：

```
請創建一個簡單的待辦事項應用，包含以下功能：
- 添加新任務
- 標記任務為完成
- 刪除任務
- 顯示所有任務
- 使用 HTML、CSS 和 JavaScript
- 創建一個 index.html 文件
```

**觀察重點**:
- Agent 如何自動創建文件
- 如何生成完整的 HTML 結構
- 如何添加 CSS 樣式
- 如何實現 JavaScript 功能

### 練習 2: 代碼重構和優化
**任務**: 讓 Agent 重構現有代碼

**操作步驟**:
1. 在 `sample-projects/todo-app/` 中創建一個簡單的 JavaScript 文件
2. 添加一些可以優化的代碼
3. 使用 Agent 模式，輸入：

```
請重構這個代碼，使其更加模組化、可讀性更好，並添加錯誤處理
```

**觀察重點**:
- Agent 如何分析現有代碼
- 如何提出改進建議
- 如何實施重構

### 練習 3: 添加新功能
**任務**: 讓 Agent 為現有應用添加新功能

**操作步驟**:
1. 基於之前的待辦事項應用
2. 使用 Agent 模式，輸入：

```
請為這個待辦事項應用添加以下功能：
- 任務優先級（高、中、低）
- 任務分類（工作、個人、購物等）
- 按優先級和分類篩選任務
- 任務統計（總數、完成數、未完成數）
```

**觀察重點**:
- Agent 如何理解現有代碼結構
- 如何添加新功能而不破壞現有功能
- 如何更新 UI 和邏輯

### 練習 4: 錯誤修復
**任務**: 讓 Agent 修復代碼中的錯誤

**操作步驟**:
1. 在代碼中故意引入一些錯誤
2. 使用 Agent 模式，輸入：

```
這個代碼有一些錯誤，請幫我修復它們
```

**觀察重點**:
- Agent 如何識別錯誤
- 如何提供修復方案
- 如何驗證修復結果

## 🔍 觀察要點

### Agent 模式的特點
1. **自主性**: Agent 會自動執行多個步驟
2. **工具使用**: 會使用各種工具（讀取文件、編輯代碼、執行命令等）
3. **上下文理解**: 能夠理解整個專案的結構
4. **迭代改進**: 會根據結果進行調整和改進

### 工作流程
1. **理解**: 分析請求和代碼上下文
2. **探索**: 搜尋相關文件和資源
3. **計劃**: 制定實施計劃
4. **執行**: 實施變更
5. **驗證**: 檢查結果並修復問題
6. **完成**: 總結所做的更改
