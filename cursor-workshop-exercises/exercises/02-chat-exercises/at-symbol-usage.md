# @ 符號使用練習

## 🎯 練習目標
掌握 Cursor Chat 中各種 @ 符號的使用方法，提高 AI 對上下文的理解

## 📋 @ 符號類型

### @Files - 引用特定文件
**用途**: 讓 AI 針對指定文件進行分析與修改

**練習 1: 文件分析**
1. 在 `sample-projects/todo-app/` 中創建一個 `utils.js` 文件
2. 添加一些工具函數
3. 在 Chat 中使用：
```
@Files utils.js 請分析這個文件中的函數，並建議改進方案
```

**練習 2: 文件修改**
1. 使用 @Files 引用一個現有文件
2. 輸入：
```
@Files index.html 請為這個 HTML 文件添加響應式設計
```

### @Folders - 引用整個資料夾
**用途**: 提供更完整的上下文，適用於跨文件或模組的變更需求

**練習 3: 資料夾分析**
1. 在 Chat 中使用：
```
@Folders sample-projects/todo-app/ 請分析這個專案的結構，並建議改進方案
```

**練習 4: 跨文件重構**
1. 使用 @Folders 引用整個專案
2. 輸入：
```
@Folders sample-projects/todo-app/ 請重構這個專案，使其更加模組化
```

### @Code - 引用特定代碼片段
**用途**: 針對特定的程式碼片段、函式或符號建立引用

**練習 5: 函數分析**
1. 在代碼中選擇一個函數
2. 使用 @Code 引用
3. 輸入：
```
@Code 請分析這個函數的複雜度，並建議優化方案
```

**練習 6: 代碼片段修改**
1. 選擇一段需要修改的代碼
2. 使用 @Code 引用
3. 輸入：
```
@Code 請將這段代碼改為使用 async/await 語法
```

### @Docs - 連結內部文件
**用途**: 提供設計規格、API 文件等參考資料

**練習 7: 文件引用**
1. 創建一個 `docs/api.md` 文件
2. 添加 API 文檔
3. 在 Chat 中使用：
```
@Docs docs/api.md 請根據這個 API 文檔創建一個客戶端實現
```

### @Git - 引用 Git 歷史
**用途**: 理解開發背景與修改原因

**練習 8: Git 歷史分析**
1. 在 Chat 中使用：
```
@Git 請分析最近的提交歷史，並總結主要的變更
```

**練習 9: 變更追蹤**
1. 使用 @Git 引用
2. 輸入：
```
@Git 請幫我理解為什麼要進行這些變更
```

### @Past Chats - 引用過往對話
**用途**: 讓 AI 延續上下文理解，避免重複敘述

**練習 10: 對話延續**
1. 在之前的對話中討論過某個主題
2. 在新的對話中使用：
```
@Past Chats 請基於我們之前的討論，繼續改進這個功能
```

### @Cursor Rules - 使用自訂規則
**用途**: 作為操作依據

**練習 11: 規則應用**
1. 創建 `.cursor/rules` 文件
2. 添加專案規則
3. 在 Chat 中使用：
```
@Cursor Rules 請根據專案規則來重構這段代碼
```

### @terminals - 引用終端操作
**用途**: 將 Terminal 操作過程加入上下文

**練習 12: 終端上下文**
1. 在終端中執行一些命令
2. 在 Chat 中使用：
```
@terminals 請根據終端的輸出，幫我解決這個問題
```

### @Lint Errors - 引用 Lint 錯誤
**用途**: 針對問題進行修正建議

**練習 13: 錯誤修復**
1. 在代碼中引入一些 Lint 錯誤
2. 在 Chat 中使用：
```
@Lint Errors 請修復這些 Lint 錯誤
```

### @Web - 網路搜尋
**用途**: 直接在網路上搜尋資料

**練習 14: 網路搜尋**
1. 在 Chat 中使用：
```
@Web 請搜尋最新的 React 18 新功能，並幫我更新代碼
```

### @Recent Changes - 引用最近變更
**用途**: 追蹤變更範圍並進行後續調整

**練習 15: 變更追蹤**
1. 在 Chat 中使用：
```
@Recent Changes 請基於最近的變更，幫我更新相關的文檔
```

## 🔍 組合使用練習

### 練習 16: 多個 @ 符號組合
```
@Files utils.js @Folders sample-projects/todo-app/ @Cursor Rules 
請根據專案規則，分析 utils.js 文件，並為整個專案提供改進建議
```

### 練習 17: 複雜上下文
```
@Code @Git @Past Chats @Web
請基於我們之前的討論、Git 歷史、選中的代碼，並搜尋最新的最佳實踐，
來改進這個功能
```

## 💡 最佳實踐

### 1. 明確指定範圍
- 使用 @Files 進行精確的文件操作
- 使用 @Folders 進行跨文件的重構
- 使用 @Code 進行特定代碼片段的修改

### 2. 提供足夠的上下文
- 結合多個 @ 符號提供完整的上下文
- 使用 @Past Chats 延續之前的討論
- 使用 @Git 了解變更歷史

### 3. 利用外部資源
- 使用 @Web 獲取最新資訊
- 使用 @Docs 引用文檔
- 使用 @terminals 了解執行環境
