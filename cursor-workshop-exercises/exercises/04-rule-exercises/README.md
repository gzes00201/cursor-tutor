# Rule 功能練習

## 🎯 學習目標
- 理解 Cursor Rules 的作用和重要性
- 學會創建和配置專案規則
- 掌握個人風格偏好的設定
- 了解 Rules 如何影響 AI 的行為

## 📋 練習題目

### 練習 1: 基礎規則創建
**檔案**: `basic-rules.md`
**目標**: 學習創建基本的專案規則

### 練習 2: 程式碼風格規則
**檔案**: `coding-style-rules.md`
**目標**: 設定程式碼風格和格式規則

### 練習 3: 架構規則
**檔案**: `architecture-rules.md`
**目標**: 設定專案架構和設計模式規則

### 練習 4: 安全規則
**檔案**: `security-rules.md`
**目標**: 設定安全相關的開發規則

### 練習 5: 測試規則
**檔案**: `testing-rules.md`
**目標**: 設定測試相關的規則

### 練習 6: 文檔規則
**檔案**: `documentation-rules.md`
**目標**: 設定文檔和註解規則

### 練習 7: 性能規則
**檔案**: `performance-rules.md`
**目標**: 設定性能優化相關規則

### 練習 8: 規則組合和優化
**檔案**: `rule-optimization.md`
**目標**: 學習如何組合和優化多個規則

## 🚀 開始練習
1. 在專案根目錄創建 `.cursor/rules` 文件
2. 按照練習題目添加相應的規則
3. 測試規則是否生效
4. 觀察 AI 如何根據規則生成代碼

## 💡 提示
- Rules 只影響 Agent 和 ⌘K 模式
- 規則應該具體且可操作
- 可以從 Chat 歷史中匯出規則
- 規則會影響 AI 的代碼生成風格和行為
