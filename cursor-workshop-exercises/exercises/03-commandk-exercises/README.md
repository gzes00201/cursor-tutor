# ⌘K 功能練習

## 🎯 學習目標
- 掌握 ⌘K 的自然語言編輯功能
- 學會使用 ⌘K 進行區塊編輯和全文件編輯
- 理解 ⌘K 的上下文理解能力
- 掌握快速提問模式的使用

## 🚀 開始練習
1. 選擇要編輯的代碼區塊
2. 按 `⌘+K` (Mac) 或 `Ctrl+K` (Windows/Linux)
3. 輸入自然語言描述你想要的變更
4. 觀察 AI 如何理解和實施你的請求

## 💡 提示
- ⌘K 會根據選中的代碼提供上下文
- 可以不斷針對同一區塊提出修改需求
- 使用自然語言描述，不需要精確的語法
- 可以要求添加功能、修復錯誤、優化代碼等
