## 🎯 學習目標
- 理解 MCP (Model Context Protocol) 的概念
- 學會配置和使用 MCP 伺服器
- 掌握外部工具整合的方法
- 了解 MCP 的限制和最佳實踐

## 🚀 開始練習
1. 在專案根目錄創建 `.cursor/mcp.json` 文件
2. 按照練習題目配置 MCP 伺服器
3. 在 Chat 中測試 MCP 功能
4. 觀察 AI 如何使用 MCP 工具

## 💡 提示
- MCP 伺服器必須在本地運行
- 配置後需要重啟 Cursor
- MCP 只支援 Tools，不支援 Resources
- 最多只能使用前 40 個工具
